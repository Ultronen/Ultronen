## Projects I maintain / 维护的项目

### [Session Archive](https://github.com/Ultronen/dsh-archived-chats)

A local-first archived-chat center for DeepSeek Harness: full-text search, native read-only previews, version restore-as-copy, ZIP backup and recovery, a protected Recycle Bin, storage accounting, retention policies, and session lineage.

项目包含跨平台 CI、201 项自动化测试、双语用户与架构文档、可复现的问题模板，以及明确的数据安全和发布边界。

[Plugin market](https://awesome-dsh-plugin.com/p/Ultronen/dsh-archived-chats/) · [npm](https://www.npmjs.com/package/dsh-archived-chats) · [Releases](https://github.com/Ultronen/dsh-archived-chats/releases)

### [Liquid Glass](https://github.com/Ultronen/dsh-liquid-glass)

A visual customization plugin for DeepSeek Harness with live translucency controls and custom full-page backgrounds.
